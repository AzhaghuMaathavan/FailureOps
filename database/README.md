# FailureOps X — Database & Storage Engine

## 1. Storage Architecture
FailureOps X utilizes a dual-tier storage strategy:
- **PostgreSQL 16 + `pgvector`**: High-performance relational metadata, dynamic JSONB query graph structures, and 2048-dimensional dense vector embeddings generated by NVIDIA Llama-Nemotron-Embed-VL-1B-v2.
- **RustFS Native S3**: High-throughput object storage on `127.0.0.1:9000` / `https://storage.shyxon.com` for immutable original source documents.

## 2. Directory Structure
```
database/
├── migrations/         # Schema migration history
├── schema/             # Canonical DDL SQL schema
│   └── 01_init_schema.sql
├── seeds/              # Deterministic demo and testing seed data
│   └── 01_demo_seeds.sql
└── README.md
```

## 3. Running Migrations & Verification
To apply schema updates against a running PostgreSQL instance:
```bash
psql -U postgres -d agentic_rag -f database/schema/01_init_schema.sql
psql -U postgres -d agentic_rag -f database/seeds/01_demo_seeds.sql
```
